# Linux System Administration

## Overview

This project focuses on practical Linux administration tasks: navigating the filesystem, inspecting metadata, managing permissions, monitoring system resources, handling processes, collecting logs with Bash, and scheduling automation with cron.

## Skills Demonstrated

- Filesystem navigation with `pwd`, `ls`, `mkdir`, and related commands
- Linux permissions and ownership concepts
- CPU, memory, and disk-resource monitoring
- Process inspection and job control
- Bash scripting for system-log collection
- Troubleshooting an SMTP-based reporting workflow
- Scheduling recurring automation with `cron`

## Key Learning

The work demonstrates how everyday Linux administration combines command-line tools, process management, scripting, and scheduled automation. It also shows the importance of validating each stage of an automated workflow instead of assuming that a script or scheduled job succeeded.

## Portfolio Value

This is useful as an entry-level systems portfolio project because it demonstrates practical Linux usage rather than only theoretical operating-system concepts.
